# Overview
AI Website Builder is a full-stack MERN application that allows users to generate responsive websites using AI. It helps users quickly create and customize websites without deep coding knowledge.

## 🛠️ Tech Stack
- Frontend: React.js, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDB
- Deployment: Render

## ✨ Features
- AI-based website generation
- User authentication (Login/Signup)
- Responsive UI design
- Live preview of generated website
- Easy customization

## 📂 Folder Structure
websiteBuilder/
│── client/   (React frontend)
│── server/   (Node.js backend)

## ⚙️ Installation

1. Clone the repository
git clone https://github.com/your-username/websiteBuilder.git

2. Install dependencies
cd client
npm install

cd ../server
npm install

3. Run the project
cd server
npm start

cd client
npm start
